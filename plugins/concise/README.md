Concise Plugin
===

## Purpose

Write, rewrite, and review Markdown documentation and diagrams that are fast to read.

## Skills

| Skill             | Description                                                                 |
|-------------------|-----------------------------------------------------------------------------|
| `concise-docs`    | Section limits, ordering rules, and a script that verifies them             |
| `concise-diagram` | Diagram rules for terminal, Markdown, and HTML, with check and icon scripts |
